# typst-basic-zh

一個適用於 [Typst](https://typst.app/) 的簡易中文筆記模板。主要用於課堂筆記、讀書摘要、公文草稿或單篇文章，都能用一份 `basic-zh.typ` 快速產出排版整齊的中文 PDF。

## 特色

- **開箱即用的中文排版**：預設中文字體、A4 頁面、頁碼置中，無須自行調整。
- **臺灣公文風格的標題與清單**：標題層級為 `壹、→ 一、→ (一) → 1. → (1)`，編號清單為 `1. → (1) → A. → (A) → a. → (a)`。
- **大型報告模式（選填）**：開啟 `isLargeReport` 後，可在最上層多加一層置中的「第一章」，並且每章另起新頁。
- **選填參考文獻**：傳入 `bib` 參數才載入參考文獻，沒有參考文獻的文件也能直接編譯。
- **隨頁註引用**：引用以註腳呈現，不輸出文末參考文獻清單。
- **一組行內樣式函式**：重點強調、教學設例、個人想法、行內引用、右側註解。

## 環境需求

1. 安裝 [Typst](https://github.com/typst/typst#installation)（命令列版）。
2. 建議安裝下列字型（模板已設定，缺少時 Typst 會自動替補，但外觀會不同）：
   - Times New Roman、Arial
   - 微軟正黑體（`Microsoft JhengHei UI`）
   - 新細明體（`PMingLiU`）、標楷體（`DFKai-SB`）
   - [TaiwanPearl 台灣圓體](https://github.com/max32002/TaiwanPearl) 的 Light 版本
   - [Zhuque Fangsong 朱雀仿宋](https://github.com/TrionesType/zhuque)

## 快速開始

1. 將 `basic-zh.typ` 複製到你的專案資料夾。
2. 新增一個內容檔，例如 `note.typ`：

   ```typ
   #import "basic-zh.typ": *

   #show: project.with(
     title: "民法債編總論筆記",
     authors: "授課老師：何孝元教授",
   )

   = 前言

   這是一份用 Typst 撰寫的中文筆記。我可以用 #keyword[重點強調] 標示重點，
   或用 #hypo[教學設例] 寫下假設情境。
   ```

3. 編譯成 PDF：

   ```powershell
   typst compile note.typ
   ```

   編譯後會產生 `note.pdf`。

> 提示：開發時可用 `typst watch note.typ` 讓 Typst 監看檔案異動並自動重新編譯。

## `project` 參數說明

`project` 是模板的主函式，以 `#show: project.with(...)` 套用到整份文件。

| 參數            | 型別             | 預設值  | 說明                                                       |
| --------------- | ---------------- | ------- | ---------------------------------------------------------- |
| `title`         | 字串             | `""`    | **必填**。主標題。                                         |
| `title-thanks`  | 內容／`none`     | `none`  | 標題的註解，例如「本文為某計畫成果」，會以腳註呈現。       |
| `subtitle`      | 內容／`none`     | `none`  | 副標題。                                                   |
| `authors`       | 字串／字典／陣列 | `()`    | 作者，可傳純字串、單一字典或陣列（詳見下節）。             |
| `bib`           | 字串／`none`     | `none`  | 參考文獻檔路徑（`.yml` 或 `.bib`）。不傳則不載入參考文獻。 |
| `isLargeReport` | 布林             | `false` | 是否為大型報告（見下節）。                                 |

### 作者欄位（`authors`）

`authors` 支援三種寫法：

```typ
// 1. 單純一個字串
authors: "何孝元"

// 2. 一位作者並附上職銜（以腳註呈現）
authors: (name: "何孝元", thanks: "國立臺北大學法律學系")

// 3. 多位作者
authors: (
  (name: "何孝元", thanks: "國立臺北大學法律學系"),
  "蔡蔭恩",
)
```

多位作者之間會以「、」連接。

### 大型報告模式（`isLargeReport`）

設定 `isLargeReport: true` 後：

1. 在現有標題層級之上**再加一層「第一章」**（置中、字級較大）。
2. 第一層標題**另起新頁**。

```typ
#show: project.with(
  title: "全學年刑法總則筆記",
  isLargeReport: true,
)

= 導論          // 顯示為「第一章 導論」並另起新頁
== 問題意識     // 顯示為「壹、問題意識」
=== 小結        // 顯示為「一、小結」
```

### 參考文獻（`bib`）

把參考文獻檔（例如 `ref.yml`）路徑傳入 `bib` 即可載入；引用仍以**腳註**呈現，文末**不會**輸出參考文獻清單。

```typ
#show: project.with(
  title: "我的文章",
  bib: "ref.yml",
)
```

若不需參考文獻，直接省略 `bib`，文件仍可正常編譯。

## 行內樣式函式

模板提供一組行內函式，方便標示不同性質的內容。使用前請先 `#import`。

| 函式           | 用途                           | 範例                           |
| -------------- | ------------------------------ | ------------------------------ |
| `keyword`      | 重點強調（原先字體加粗）       | `#keyword[重要]`               |
| `very-keyword` | 非常需要強調的重點（黑體粗體） | `#very-keyword[極重要]`        |
| `hypo`         | 教學設例（圓體）               | `#hypo[假設小明……]`            |
| `thought`      | 個人想法（仿宋）               | `#thought[我認為……]`           |
| `inquote`      | 行內引用（楷體）               | `#inquote[被引用之文字]`       |
| `rightNote`    | 靠右的小字註解                 | `#rightNote[（0218 W1 節一）]` |

## 標題與清單的編號規則

### 標題（預設模式）

| 層級   | 寫法         | 顯示結果           |
| ------ | ------------ | ------------------ |
| 第一層 | `= 標題`     | `壹、標題`（置中） |
| 第二層 | `== 標題`    | `一、標題`         |
| 第三層 | `=== 標題`   | `(一) 標題`        |
| 第四層 | `==== 標題`  | `1.標題`           |
| 第五層 | `===== 標題` | `(1) 標題`         |

開啟 `isLargeReport` 後，各層級整體後移一層，最上方多出 `第一章 N`。

### 編號清單

```typ
+ 第一項        // 1.
+ 第二項        // 2.
  + 子項        // (1)
```

依層級依序為 `1. → (1) → A. → (A) → a. → (a)`。

## 排版細節

- **頁面**：A4，左右邊距 3cm、上下 2.5cm，頁碼置中。
- **內文**：新細明體 12pt，行距 1.1em，段距 1.6em，首行**不**縮排。
- **註腳**：文內標籤為黑體上標，底部採懸掛縮排。
- **封面**：首頁為置中的標題、副標題與作者，其下接目錄。

# typst-basic-zh

A simple Chinese note-taking template for [Typst](https://typst.app/). Whether you are writing class notes, reading summaries, draft official documents, or a standalone article, a single `basic-zh.typ` gets you a neatly typeset Chinese PDF.

For more information and a tutorial of usage, please see [README-zh.md](https://codeberg.org/zhenhuang/typst-basic-zh/README-zh.md).

## Features

- Chinese typography that works out of the box
- Taiwanese official-document heading and list styles
- A set of inline style functions
